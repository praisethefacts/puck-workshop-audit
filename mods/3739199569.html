What it is #

A Puck arena/scenery replacement with a day-and-night lighting system: a custom arena prefab and skybox (33.6 MB Unity AssetBundle tlanskybox), two looping ambient tracks, bloom/fog/shadows/floodlight controls, an in-game control panel (UI Toolkit), and a /atod admin command to set the server clock. It is a client-and-server mod: dedicated servers get the server side plus the time broadcast, clients render the arena and follow the server clock. The 192 KB TLANArena.dll is required — it loads the bundle, spawns the arena, and patches three chat methods plus registers one Netcode named message.

Code analysis #

Bootstrap. TLANArena.ArenaMod : IPuckPlugin (ArenaMod.cs:11) creates Harmony id com.tlan.arena and patches its own assembly (:29-30), loads server settings server-side and client+server settings client-side, then creates a DontDestroyOnLoad TLANArena_Driver GameObject with ArenaDriver (and ArenaUI on clients) (:42-48). OnDisable destroys it and UnpatchSelf() (:62-71). ArenaDriver subscribes to game events Event_OnSceneLoaded, Event_OnSceneUnloaded, Event_Everyone_OnLevelSpawned, Event_Everyone_OnClientConnected (ArenaDriver.cs:35-38) and spawns/despawns the arena on level_default only (:53-61, :105-118). It deliberately refuses to spawn if dem's Scenery Loader (workshop id 3566470321) is enabled (ArenaDriver.cs:144-164) — a compatibility guard, nothing more.

Harmony patches (exactly three):

  • ChatManager.Client_SendChatMessageRpc — prefix + finalizer used only to set/clear a "suppress the 'Unknown command' echo" flag around handled / commands (ChatCommandDispatchPatch.cs:8-33).
  • ChatManager.Client_SendChatMessage — prefix returns false (consumes the message) when a registered client command handled it (ClientChatCommandPatch.cs:9-16).
  • ChatManager.Server_SendChatMessage(string, string, ulong[]) — prefix to suppress the unknown-command reply (UnknownCommandSuppressPatch.cs:14). No transpilers; nothing patched outside ChatManager. /atod is admin-gated via Player.AdminLevel / AdminManager.IsSteamIdAdmin (ServerCommands.cs:112-149) and only changes a time-of-day enum/float (:63-110).

Network. No HttpClient, WebClient, WebRequest, Socket, TcpClient, UdpClient or Dns calls anywhere; evidence/api_surface.txt [Network] has exactly 2 hits, both the local audio loader below. Its only networking is Unity Netcode's own CustomMessagingManager: a named message TLAN/Arena/Time carrying one float seconds-of-day (ArenaProtocol.cs:9-45), broadcast every BroadcastIntervalSeconds by the server and pushed to each joining client (ServerTimeSync.cs:36-194, handler at :88-98), with a 4-byte bounds check on receive (ArenaProtocol.cs:52). No Steamworks API, no GetAuthTicket, no credentials, no session tokens, no cookies. Server password is not touched anywhere.

Filesystem. Reads: its own AssetInformation.json in the bundle folder (AssetInformation.cs:42-72), logo.png for the UI (ArenaUI.cs:730), its config JSONs. Writes: <game dir>/config/TLANArena/client.json (ClientSettings.cs:1122-1124, write at :1428-1429) and tlanarena_config.json next to the server executable (ServerSettings.cs:78, write at :110). Both are plain JsonUtility settings dumps; no user documents, no startup folders, no temp execution. No downloads, no uploads.
