Verdict: BENIGN / WITH CAVEATS Risk score: 25/100 (Low–Moderate) Kind: managed .NET mod + one native x64 DLL + a PowerShell dev helper Author: Ponce (SteamID64 in evidence/pe_info.txt and workshop metadata) · On-disk size: 47.5 MB

What it is #

A large "centre" mod for Puck that bundles several quality-of-life features plus an in-game web panel: custom hats/boards/crowd bundles, a goal-horn/media pack, an MOTD/news browser and a league-registration UI. The bulk of the 47.5 MB is media (.webm, .mp4, .mp3) and Unity .bundle files; only three files contain executable logic: PonceArenaTweaks.dll (managed), native/x64/WebView.dll (native, third-party) and native/fetch-ublock.ps1 (helper script).

Contents #

  • 108 files. Notable: PonceArenaTweaks.dll (14,370,304 B), native/x64/WebView.dll (140,288 B), native/fetch-ublock.ps1 (3,101 B), tags/*.mp3, media/*.webm|*.mp4, hats.bundle, boardads, crowdmod, AssetBundles.
  • PonceArenaTweaks.dll: PE32, i386/AnyCPU, .NET (Mono), unsigned, no overlay, no P/Invoke. Large but conventional managed mod code (Unity, Harmony, Newtonsoft.Json, Steamworks.NET).
  • native/x64/WebView.dll: genuine third-party gree/unity-webview plugin (exports _CWebViewPlugin_*), renamed but byte-compatible with the open-source project. It is the embedded browser used by the in-game panel.
  • All hashes: evidence/hashes_sha256.txt; PE facts: evidence/pe_info.txt; decompiled C#: sources/; REA note: ../_harness/rea/3800009738__WebView.dll.md.

Code analysis #

  • Network: only HTTPS to the author's own backend poncepuck.net — staff_ids.php, tag_prefs.php, reminders.php, commend.php, friends.php. Custom SimpleHttpsClient with certificate validation (ServicePointManager + TLS). No analytics, no third-party hosts, no webhooks, no paste sites.
  • Filesystem: writes only under the game's config/ModHub/PonceArenaTweaks/ folder (settings, cached staff/tag lists) and ponce_account.json, which stores the mod's own account token for poncepuck.net. No reads of browser/app data, no credential stores.
  • Process / registry: Process.Start("explorer.exe", …) is used only to open/reveal exported media packs. A single registry read detects WebView2 (…\EdgeUpdate\Clients\…) — normal runtime detection, nothing written.
  • Native DLL: performs HTML/JS rendering via WebView2; it can evaluate script inside its own panel and read/write cookies for pages it loads. Capability exists, but it is only ever pointed at poncepuck.net and locally generated file:// content; no evidence of it being aimed at Steam/browser sessions.
  • fetch-ublock.ps1 (read in full): purely a developer utility — queries the GitHub releases API, downloads a uBlock Origin Chromium .zip, and expands it into native/x64/extensions/ublock0. It is never invoked by the DLL at runtime and does not run on install. Benign, but it is a script that downloads code, so it is worth knowing about.
  • Absent: no P/Invoke or shellcode, no Steam auth-ticket access, no keylogging/clipboard/ screen capture, no crypto-wallet or browser-credential paths, no persistence (no Run key / scheduled task / service), no packing or anti-debug, no auto-updater that executes downloaded binaries.

Findings #

  1. WebView plugin is a full in-game browser (native/x64/WebView.dll) — renamed open-source gree/unity-webview. Severity: info/low. It is legitimate, but any compromise of poncepuck.net would gain script execution inside the mod's panel scope.
  2. PowerShell helper downloads third-party code (native/fetch-ublock.ps1) — not called by the mod, but present on disk and user-runnable. Severity: low.
  3. Account token stored in plaintext (config/ModHub/PonceArenaTweaks/ponce_account.json) — token for the mod's own site, not Steam. Severity: low.
  4. No malicious indicator of any malware class (grabber, ransomware, miner, stealer, RAT, persistence) was found. Severity: none.

Evidence trail #

  • Method: SHA-256 inventory of all 108 files, PE header parsing (pe_info.txt), ilspycmd decompilation of the managed DLL, full byte-pattern + string scan (scan_hits.tsv, text_hits.txt), manual read of fetch-ublock.ps1, REA open_binary / inspect_managed_artifact on WebView.dll.
  • Not verified: the native WebView2 hosting code was not decompiled instruction-by-instruction; poncepuck.net server behaviour was not tested (no account to log in with).

Bottom line #

Keep. It is a legitimate large content+UI mod by a known Puck creator; the only real caveats are the embedded browser pointed at the author's site and the presence of a download-helper script that never runs on its own.
