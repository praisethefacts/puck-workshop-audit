What it is #

A tiny mod that translates in-game chat: it takes each incoming chat line and asks Google's undocumented Chrome-translate endpoint for a translation, then shows it in the chat overlay. Two files only — one small managed DLL and one JSON config.

Contents #

  • 2 files: ChatTranslator.dll (33,280 B) + chat_translator.json (44 B, language/toggle settings).
  • ChatTranslator.dll: PE32, i386/AnyCPU, .NET/Mono, unsigned, no P/Invoke, no overlay, entropy 5.64. 10 decompiled classes, ~53 KB of C#.
  • Hashes: evidence/hashes_sha256.txt; PE facts: evidence/pe_info.txt; source: sources/.

Code analysis #

  • Network: exactly one endpoint, HTTPS: https://clients5.google.com/translate_a/single?client=dict-chrome-ex&sl=auto&dt=t&tl=<lang>&q=<chat line> via UnityWebRequest.Get. Nothing else — no analytics, no telemetry, no other hosts.
  • Filesystem: only its own config (target language, toggles).
  • Absent: no process/registry access, no DllImport, no reflection loading, no obfuscation, no persistence, no input capture, no credential or token access.

Findings #

  1. Chat text is sent verbatim to a Google endpoint — every message you receive (and, depending on settings, send) leaves the machine to clients5.google.com. That is inherent to a translator, but it is third-party data exposure. Severity: low.
  2. Google's clients5.google.com/translate_a/single is an undocumented internal endpoint, so it can break or change at any time; not a security issue. Severity: info.
  3. No malware indicator of any kind. Severity: none.

Evidence trail #

  • Method: SHA-256, PE parsing, full ilspycmd decompilation (all 10 classes read), byte-pattern
    • text scan, evidence/api_surface.txt.
  • Not verified: runtime behaviour against Google (not exercised).

Bottom line #

Keep if you want chat translation — it is a clean, single-purpose mod. Understand that chat text is sent to Google to be translated.
