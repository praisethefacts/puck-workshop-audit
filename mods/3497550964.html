What it is #

The most widely used Puck cosmetic/reskin framework: it lets leagues and creators ship texture packs that this loader applies to sticks, pucks, rinks, goal nets and jerseys at runtime, plus a dev console, a frame profiler and a workshop-update checker. It is a normal managed Unity mod (single 774,144 B DLL) with a big UI layer; the DLL is required for the mod to work.

Contents #

  • 1 DLL + config files. ToasterReskinLoader.dll: PE32, i386/AnyCPU, .NET Framework v4.8 (Mono), unsigned, 3 sections, no overlay, no P/Invoke, no module refs, no resources.
  • 27 assembly references — all expected (Unity modules, 0Harmony, Newtonsoft.Json, Steamworks.NET, Puck). Notably UnityEngine.UnityWebRequestModule = live HTTP capability.
  • Hashes: evidence/hashes_sha256.txt; PE facts: evidence/pe_info.txt; decompiled C#: sources/; REA note: ../_harness/rea/3497550964__ToasterReskinLoader.dll.md.

Code analysis #

  • Network (HTTPS only):
    • https://puckstats.io/api/appearance and variants /xp, /redeem, /unlocks?steamId= — the author's cosmetic-progression backend; JSON POSTs include the player's SteamID64 and cosmetic profile.
    • https://ipapi.co/ — GeoIP lookup feeding the built-in FrameProfiler diagnostic overlay.
    • https://stellaric.pw/, http://ko-fi.com/stellaric, https://discord.gg/… — author homepage / donation / support links.
    • https://steamcommunity.com/sharedfiles/filedetails/?id=… and a workshop-browse link.
  • Filesystem: writes its own settings/pack cache in the mod config dir; keeps cached server passwords on disk via SavedServerPasswords / ServerKeyStore types.
  • Process: DevConsole type can run Process.Start(new ProcessStartInfo{ UseShellExecute = true }) — a shell-execute helper reachable only from the in-game developer console.
  • Steam: WorkshopUpdateChecker can trigger SteamWorkshopManager.DownloadItem.
  • Absent: no AppData browsing, no powershell/cmd strings, no stratum/xmrig, no wallet/exodus/metamask paths, no GetAsyncKeyState/clipboard/screen capture, no CurrentVersion\Run persistence, no base64 download-and-execute, no obfuscation or reflection loading, no unsigned native code.

Findings #

  1. Sends SteamID64 + cosmetic data to puckstats.io (UsageAnalyticsAPI, HeartbeatPayload). Severity: low–moderate (privacy; disclosed in its UI, TLS).
  2. Third-party GeoIP call to ipapi.co from the profiler. Severity: low (privacy).
  3. Cached server passwords kept on disk (SavedServerPasswords, ServerKeyStore) — a convenience feature, but plaintext credentials for game servers on disk are a real risk if the machine is shared or compromised. Severity: moderate.
  4. Shell-execute via dev console — intended for launching pack folders/tools; a capability worth knowing, not evidence of misuse. Severity: low.
  5. No malware indicator (grabber / ransomware / miner / stealer / RAT / persistence / evasion) was found. Severity: none.

Evidence trail #

  • Method: SHA-256, PE parsing, ilspycmd decompilation, byte-pattern + UTF‑16/ASCII string scan (evidence/scan_hits.tsv, text_hits.txt), REA open_binary, inspect_managed_artifact, inspect_managed_native_boundaries, inspect_managed_members, inspect_analysis_view (see ../_harness/rea/3497550964__ToasterReskinLoader.dll.md).
  • Not verified: puckstats.io server-side handling of the SteamID64s was not tested.

Bottom line #

Keep, but know that it phones home with your SteamID64 and cosmetic stats, and it stores game-server passwords in its own config folder. Nothing malicious was found.
