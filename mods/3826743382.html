What it is #

An arena pack for Puck by a different author from the Rink/TLAN mods: a 12.7 MB glTF model of the Ralph Engelstad Arena plus three WAV files (goal horn, "stand up and cheer", "fight on Sioux"), a small DLL that plays them as a positional PA/goal-horn system, and two JSON manifests. The arena itself is loaded by the separate Arena Loader mod (3802863574) — this pack ships the .al.json manifest that loader reads (Ralph Engelstad Arena.al.json). The DLL adds immersive audio, a jumbotron board variant toggled with F10, live score text on the arena boards and removal of the bench barrier glass; it never touches the network, the registry or another process.

Code analysis #

Bootstrap. RalphEngelstadAudio.Plugin : IPuckPlugin (Plugin.cs:6) creates DontDestroyOnLoad("RalphEngelstadAudioHost") with one ArenaAudioController, and destroys it in OnDisable (Plugin.cs:20-22,33-49). No Harmony patches — the whole mod runs off two game events: Event_Everyone_OnGoalScored and Event_Everyone_OnGameStateChanged (ArenaAudioController.cs:100-101, removed at :104-112).

Audio loading. FindAudioDirectory probes five candidate paths for the three WAVs (ArenaAudioController.cs:114-134): <dll dir>\audio, <dll dir>\Ralph Engelstad Arena\audio, two hardcoded developer paths [local path], and [local path]. Only three fixed filenames are ever opened (goal_horn.wav, stand_up_and_cheer.wav, fight_on_sioux.wav), and only if <dir>\goal_horn.wav exists (:128). LoadWav does a minimal RIFF chase to the data chunk and builds an AudioClip from the PCM (:136-167) — a hand-rolled WAV parser, no code loading.

Scene interaction (all local rendering). EnsureSpeakerRig finds the arena root by name (Arena Ralph Engelstad Arena / … BETA), waits until its REA_Board_Box node and a renderer exist, then builds seven AudioSource "speaker" objects with 3D rolloff, echo filters and reverb-zone tuning (:202-286,538-566). ApplyBoardState toggles REA_Board_Box* vs REA_Board_Cylinder* (F10, persisted in PlayerPrefs key REA_BoardCylinder) (:288-320,903-909). CreateLiveScoreboards/UpdateLiveScore create TMP text objects on REA_ScoreAnchor_* nodes and write score/clock/period from GameState (:371-445,489-526). HideVanillaScoreboards/RestoreVanillaScoreboards toggle the game's own Scoreboard components, restoring them on destroy (:460-487,477-487). CutBenchBarrierGlass clones the readable Barrier Glass mesh, drops triangles whose centroid is behind the bench and disables Barrier Pillars, restoring the original mesh afterwards (:568-657). MuteVanillaHorns mutes Blue Goal/Red Goal audio sources and restores them (:659-687): state is always rolled back in OnDestroy.

Input. Keyboard.current F6/F7/F8/F9/F10 fire the announcement clips and the board toggle (:900-931) — Unity's input system only; no raw Win32 hooks, no GetAsyncKeyState.

Absent. No network APIs of any kind (no UnityWebRequest, HttpClient, WebClient, sockets, DNS); no registry; no process creation or shell; no P/Invoke/Marshal; no Assembly.Load; no persistence (only PlayerPrefs, which the engine owns); no crypto or file encryption; no clipboard/screen capture. File access is limited to Directory.Exists/File.Exists/File.ReadAllBytes on the five fixed candidate folders and three fixed WAV names (evidence/api_surface.txt [FileSystem] — exactly four lines, ArenaAudioController.cs:128,138,142).

Findings #

  1. Hardcoded developer paths in the audio search list (ArenaAudioController.cs:121-123: [local path] and [local path]). Leftover build-environment paths, and the workshop id in them (3802863574) is Arena Loader's, not this mod's — evidence that the author reuses a shared Arena-Loader-era template. Harmless: the paths are only probed for goal_horn.wav and are read-only. Severity: informational.
  2. Hand-rolled WAV parsing of files from disk (:136-167). Malformed/large WAV can throw inside LoadWav; the caller does not wrap it, so a broken asset can produce a logged plugin error. No security impact (no native code, no writes). Severity: low.
  3. Deliberate, reversible mutation of shared scene objects: vanilla scoreboards hidden, vanilla goal horns muted, the game's barrier-glass mesh swapped for a cut copy (:568-657, :460-487, :659-687). All three are restored in OnDestroy, so nothing persists after the mod is disabled. Severity: informational.
  4. No Harmony and no code from data. The only executable content is the shipped managed DLL; .glb and .wav are consumed as assets. This mod cannot be used as a code-execution vector by a malicious third-party arena pack. Severity: informational.
  5. Absent categories (checked against evidence/api_surface.txt + all 3 decompiled files): no network, no registry, no process, no P/Invoke, no assembly loading, no persistence beyond engine PlayerPrefs, no credential/token access, no crypto, no keylogging/screen capture. Severity: n/a.

Bottom line #

A clean, self-contained arena audio/scoreboard mod: WAVs and one glTF model, one small managed DLL that only reads its own media files and toggles in-scene objects it restores on unload. No network, no persistence, no process or registry access — the only oddity is two leftover developer paths in its audio search list.
