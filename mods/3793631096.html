What it is #

RankUp is a community-run EU ranked queue for Puck ("RankUp is the EU queue for Puck. Servers: Prague and Frankfurt… not official Puck ranked", per the Workshop description). The mod adds a full in-game ranked interface — queue widget, match board, ELO ladder, profile pages, match history, challenge/XP tracking and Discord linking — and talks to a community matchmaking backend to place you in a match. It is a client for a third-party service, not a game-mechanics cheat.

Code analysis #

Bootstrap / Unity surface — IPuckPlugin entry point; Harmony patches only touch the game's UI layer: UIManager.CheckMouseRequirement, UIPauseMenu.Initialize, UIPlay.Initialize (+ a UIPlay show patch). The rest is UnityEngine.UIElements drawing (RankUpShell, RankUpPages, RankUpTheme, custom RU* widgets). No gameplay/render/netcode patches.

Networking — plain HttpWebRequest against http://78.40.210.102:8787 (raw IP, no TLS; URL overridable through the config file). Endpoints observed in source:

JSON bodies carry {steamId, name, role, region, text}; 8 s timeouts, Proxy = null (no proxy use). Responses populate the UI and are also used to auto-connect you to your match.

Server-directed connect — ConnectToMatch() takes Ip, Port and Password from the backend's match payload and calls the game's ConnectionManager.Client_StartClient(ip, port, password). This is exactly what a matchmaking mod has to do, but it means the backend decides which server you join, including its join password.

URL opening — OpenUrl() calls Application.OpenURL on strings supplied by the backend (DiscordUrl, VoiceUrl, per-team voice URLs), with https://discord.gg/Rzk8jswWYe as fallback. Steam/the OS will prompt for non-https/steam protocols, but a compromised or malicious backend could offer any URI.

Player identity — reads SteamID64 + persona name from the game's own Steam integration and fetches avatars through SteamIntegrationManager; no Steam auth ticket or session token is ever read or transmitted.

Local I/O — the only file access in the whole assembly is its own config JSON next to the DLL (create-if-missing, read). No browser credential paths, cookies, wallet files, %APPDATA% staging, registry keys, Process.Start, scheduled tasks, clipboard, keyboard hooks, screen capture, Assembly.Load, base64/reflection loaders, crypto or AES/decrypt loops. System.Diagnostics is referenced only by AssemblyInfo.cs (assembly metadata), not by code.

Findings #

  1. Cleartext HTTP to a raw IP — Medium. SteamID64, persona name, region, queue state and ranked chat text travel unencrypted to 78.40.210.102:8787. Anyone on the network path can read them, and a MITM can alter responses (including the server IP/port you are told to connect to).
  2. Backend-directed server connection — Low. Match IP/port/password come from the backend, so the operator can point your client at any server (with a password). Inherent to matchmaking; trust-based.
  3. Remote-supplied URL opens — Low. Discord/voice URLs come from backend payloads and are passed to Application.OpenURL; OS protocol confirmation limits the practical impact.
  4. Community telemetry — Informational. Queue state, ELO and chat are stored by a third-party operator; no privacy policy ships with the mod. 266 subscribers, 567 views, updated 2026-09-27.
  5. Clean-code positives — Informational. Unsigned but un-obfuscated, no native code, no credential/wallet/persistence/injection APIs, no file writes outside its own config, no evidence of any stealer/miner/ransomware/RAT behaviour.

Bottom line #

Legitimate community ranked mod with ordinary privacy caveats, not malware. It ships no stealer, grabber, miner, ransomware or persistence code, and the only file it touches is its own config. Keep it if you play the RankUp EU queue; remove it if you don't. Be aware that your SteamID64, in-game name and ranked chat text are sent unencrypted to a community server at a bare IP address, and that the backend decides which game server you connect to.
