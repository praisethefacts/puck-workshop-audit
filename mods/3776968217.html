Verdict: SUSPICIOUS Risk score: 45/100 (Moderate) Kind: managed .NET mod, obfuscated Author: RHL league (see evidence/FACTS.md) · On-disk size: ~0.9 MB

What it is #

A companion client for a Russian-language Puck league ("RHL"): an in-game locker/shop for league skins and goal effects (premium subscription upsell to rhlpremium.ru), plus a MultiAccountGuard component that fingerprints the machine and reports which plugins/assemblies are loaded, so the league can detect multi-accounting and patched clients.

It is not malware, but it is the most invasive mod in this collection: hardware fingerprinting, loaded-module enumeration and telemetry to a hard-coded raw IP over plain HTTP, behind deliberate obfuscation. That combination is why it is flagged.

Contents #

  • 4 decompiled C# files, ~914 KB total. MultiAccountGuardClient.dll is obfuscated: every type, method and field is renamed to _00A0, _2004, _2005, … and all strings are stored in an XOR-encrypted blob.
  • PE: i386/AnyCPU managed (.NET/Mono), unsigned, no overlay.
  • Obfuscation: 645-entry string table in a 15,275-byte static array, decoded at runtime with _4[i] = _4[i] ^ i ^ 0xAA (see sources/.../D6DD96C5-…cs, static constructor). This was reversed offline and all 645 strings were recovered to ../_harness/rhl_strings_all.txt (filtered highlights in ../_harness/rhl_strings.txt).
  • Hashes: evidence/hashes_sha256.txt; PE facts: evidence/pe_info.txt; source: sources/.

Code analysis #

  • Identity / fingerprinting: GetVolumeInformation (disk volume serial), Environment.GetEnvironmentVariables(), SteamID64 and Unity's SystemInfo.deviceUniqueIdentifier are combined into an HWID. K32EnumProcessModulesEx + K32GetModuleFileNameExW enumerate the modules loaded into the process (i.e. which other mods/DLLs you have).
  • Telemetry endpoints:
    • http://155.212.135.111:8081/report — plain HTTP to a hard-coded IP, no TLS, no domain.
    • https://rhladminpanel.morfikgl.beget.tech/puck/report-plugin — loaded-plugin report.
    • https://rhladminpanel.morfikgl.beget.tech/puck/report-integrity — "Integrity report sent: {0} assemblies, {1} patches, {2} bytes" (client-integrity / anti-cheat snapshot).
    • X-Api-Key header is attached to these reports.
  • Content endpoints (normal): https://rhladminpanel.morfikgl.beget.tech/rhl-models/bundles/, /puck/skins?ids=…, /league-reskins/S7/…png, https://rhlpuck.morfikgl.beget.tech/lk/api/companion/locker?steamId= (fetches your purchased skins/effects).
  • Log strings (recovered): "Client fingerprint reporter started", "Missing SteamID or HWID — skipping fingerprint send", "Could not read system volume serial", "Integrity report sent", "Plugin report sent for …".
  • Absent: no file encryption/ransom behaviour, no browser/wallet/credential paths, no keylogging or clipboard capture, no persistence (no Run key / task / service), no process injection, no download-and-execute of binaries (only Unity asset bundles and PNGs).

Findings #

  1. HWID fingerprint exfiltrated (volume serial + env vars + device id + SteamID64) to the league's hosts. Severity: high-privacy / moderate overall — a persistent hardware identifier tied to your Steam account, held by a third party.
  2. Plain-HTTP report to a bare IP (http://155.212.135.111:8081/report). Severity: moderate — anything sent there can be read or modified on-path, and the purpose of that host is not documented.
  3. Enumerates loaded modules and reports plugin/integrity data. Severity: moderate — effectively an anti-cheat/telemetry agent inside your game, with visibility into every other mod you run.
  4. Obfuscation (renamed symbols + XOR string table). Severity: moderate — no legitimate reason to hide strings that are just UI text, URLs and log messages; it defeats casual review.
  5. Undocumented X-Api-Key shipped in the binary. Severity: low (key is client-side and therefore not a secret), but it implies a privileged server API.
  6. No evidence of malware behaviour. Severity: none.

Evidence trail #

  • Method: SHA-256, PE parsing, ilspycmd decompilation, REA inspect_managed_artifact / inspect_managed_members, plus a custom offline decoder for the XOR string table (_harness/rhl_strings_all.txt).
  • Not verified: server-side handling at 155.212.135.111 and *.beget.tech was not tested (no account, and testing would mean sending real data); the obfuscated control flow was reviewed by strings + API surface, not by fully de-obfuscating every method.

Bottom line #

Not malware, but treat it as an anti-cheat/telemetry client. It reads a hardware ID and the list of your loaded mods and sends them to the league, partly over unencrypted HTTP. Keep it only if you actually play in that league; otherwise remove it.
