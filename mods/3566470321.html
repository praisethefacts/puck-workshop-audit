What it is #

A Puck (Unity) plugin that replaces the rink/arena scene with community-made scenery packs, adds /sl chat commands, and tweaks arena audio and lighting. It ships one small managed DLL (SceneryChanger.dll, 138 KB) plus a 22 MB Unity AssetBundle (AssetBundles/outdoorhockey, an outdoor-hockey scene) and JSON metadata. The DLL is required — it contains the Harmony patches that swap the scene at runtime. It also implements an "encrypted map pack" format (.abx) so community authors can ship scrambpled bundles with a shared key, which is the one part of this mod worth reading carefully; it is decryption only, not encryption of the user's data.

Crypto — the "encrypted map pack" feature. This is the only crypto in the mod and it is decrypt-only:

  • MessageObfuscation (MessageObfuscation.cs:9) holds a hard-coded 48-char key "knewdarklongcorrectlythirdgreatestspokenmotorvotes"; Encode applies a SHA-256-based XOR keystream then Base64, Decode reverses it (:32). This is obfuscation of the chat payload, not a secret — anyone can reverse it; it is not encryption of user data.
  • AbxCacheDecryptor parses a custom ABX1 container: magic ABX1, version 1, 16-byte IV, int32 ciphertext length, ciphertext, 32-byte HMAC tag (AbxCacheDecryptor.cs:93-160). Per-pack key contentKey32 is expanded with SHA256(contentKey32 || "enc") for AES-256-CBC/PKCS7 and SHA256(contentKey32 || "mac") for HMAC-SHA256 (encrypt-then-MAC, constant-time compare FixedEq, :120-151). AbxLoader.cs:11-16 is the in-memory variant (AssetBundle.LoadFromMemory).
  • Where the key comes from: SceneInformation.contentKey64 (SceneryChanger.Model/SceneInformation.cs:13), a 32-byte key as 64 hex chars or Base64 (KeyParser.cs:7-27). It is not embedded in the DLL. It arrives either (a) from the user's own SceneryLoaderConfig.local.json, or (b) inside the !LoadMap chat message a server sends: the chat postfix serialises the current SceneInformation — key included — into "!LoadMap " + MessageObfuscation.Encode(JsonConvert.SerializeObject(...)) (UIChatControllerPatch.cs:131) and the client decodes/deserialises it (:38-78). So the key is a community-shared pack key transported over in-game chat, not a protected secret, and not something sent to any third party.
  • What it decrypts / what can it execute: only third-party Unity AssetBundle files (.abx), which are then loaded as assets — AssetBundle.LoadFromFileAsync (BundleLoader.cs:70-84) or AssetBundle.LoadFromMemory (AbxLoader.cs:13) followed by LoadAssetAsync<GameObject> / <Material> (BundleLoader.cs:278-292, SkyboxLoader.cs:10-24). There is no path from decrypted bytes to Assembly.Load/Assembly.LoadFrom/reflection invoke of code, so a decrypted pack cannot execute arbitrary code; it can only supply Unity assets/prefabs/shaders. Decrypted caches are written to %userprofile%/AppData/LocalLow/.../AbxCache with a hashed filename, atomically via .tmp + File.Move, and marked FileAttributes.Hidden (AbxCacheDecryptor.cs:240-259); old same-prefix caches are pruned (PruneOldBundleCaches). Hidden-attribute cache files are unusual but benign in intent and scoped to the mod's own cache naming.

Reflection. AccessTools.TypeByName("WebSocketManager"/"ConnectionManager"/"ChatManager"/"UIChat"/"SceneManager") and Traverse.Create(...).Field(...) (UIChatControllerPatch.cs:178-181) are standard Harmony-era reflection against the host game to interoperate with types the mod does not reference at compile time. No dynamic assembly loading, no InvokeMember on untrusted input.

Persistence / privilege: none. It writes only its own config and cache, does not add Run keys, tasks, services or startup shortcuts, and does not elevate.

Findings #

  1. Chat-driven remote scene directive is unauthenticated in design (feature risk, not malware). Any chat message beginning !LoadMap that reaches a client is decoded and, outside practice mode, triggers SceneLoadCoordinator.OnServerSceneDirective and is swallowed from the chat UI (UIChatControllerPatch.cs:38-78). A griefer who can get such text relayed in chat could force a scenery swap on other mod users — but only to bundles already present on the victim's disk (missing bundle aborts and restores vanilla, RinkSceneLoader.cs:87), and a swapped bundle yields Unity assets, not code. Severity: low, boundary of the mod's own design.
  2. Per-pack AES key travels in chat, and the chat obfuscation key is hard-coded. MessageObfuscation.cs:9, UIChatControllerPatch.cs:131. Anyone in the lobby can recover a pack key; this is by design for a shareable community format and exposes nothing of the user's. Severity: informational.
  3. Hidden decrypt cache files. AbxCacheDecryptor.cs:253-259 sets FileAttributes.Hidden on .u3d cache entries under the Unity persistent-data AbxCache folder; verified decrypt/verify-then-write with HMAC validation before decryption. Not evasion of the user — scoped cache hygiene. Severity: low/informational.
  4. Config can be redirected to an absolute directory. ModConfig.ResolveConfigDirectory honours an absolute configDirectory in SceneryLoaderConfig.path.json and writes SceneryLoaderConfig.local.json there (ModConfig.cs:113-145). Server-admin convenience feature; writes only a JSON settings file the user's own install controls. Severity: informational.
  5. Absolute local audio paths are loaded as audio. AssetInformation.json's musicPath/ambientAudioPath may be absolute (RinkSceneLoader.cs:793-811); only fed to Unity's audio decoder via file://. Severity: informational.
  6. All 502 binary "hits" are Unity bundle magic signatures, keyword hits 0. evidence/hits_summary.txt, evidence/scan_hits.tsv. No embedded URLs, hosts, IPs or registry paths in the DLL (full-file string scan, REA note _harness/rea/3566470321__SceneryChanger.dll.md).
  7. Absent categories (checked in sources + api_surface.txt): no HTTP/DNS/socket client of any kind; no Steam auth ticket, credentials, cookies, tokens, or clipboard/keyboard/screen access; no registry; no process creation or injection; no DllImport/native calls (0 P/Invoke, 0 module refs); no Assembly.Load; no persistence; no downloader; no AV/AMSI evasion.

Bottom line #

Keep it. The DLL is a normal Harmony scenery loader: no network calls, no persistence, no credential or process access, and its AES/HMAC code only decrypts community map bundles (the key is shared in chat by design) which are then loaded as Unity assets — it cannot run code from them. The only caveats are design-level: chat can direct your client to swap scenes if the map pack is already on your disk, and the mod's decrypt cache is written hidden under its own AppData folder.
