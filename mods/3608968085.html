What it is #

Displays a rich per-player statistics tooltip and play-by-play feed on the scoreboard (shots, saves, goals, zone events), styled through the game's UI Toolkit, and adds stats chat commands. It computes stats from collisions/game events on the server and pushes them to clients over the game's network session. Its one notable global behaviour is a Harmony prefix on Application.OpenURL that redirects Steam-community links into the Steam overlay instead of the system browser.

Findings #

  1. Global Harmony prefix on Application.OpenURL — Stats.cs:1810-1851. Any steamcommunity.com URL opened by any mod/game code in the process is routed to the Steam overlay and the browser launch is suppressed; everything else passes through. Not exfiltration, but it is process-wide interception of URL opening, and it makes behaviour depend on substring matching (url.Contains("steamcommunity.com") also matches lookalike substrings). Severity: low.
  2. Chat-command suppression patches on ChatManager — Stats.cs:1883,1897,1907,1922 plus Client_SendChatMessageRpc (:1853). Stats command text is intercepted instead of broadcast; intended, server-gated by IsDedicatedServer()/command check. Severity: informational.
  3. Stats data streamed to clients via Netcode — NetworkCommunication.cs:32,70, Stats.cs:1017,4188. Inside the game session only. Severity: informational.
  4. Writes oomtm450_stats_serverconfig.json — Stats.cs:3925. Server-side config next to the server binary. Severity: informational.
  5. Scanner MZ hit at offset 92,969 is inside IL/metadata, not a second PE — evidence/FACTS.md and evidence/scan_hits.tsv; no overlay, no extra section headers. Severity: informational.
  6. No external network or host-level API use — 0 risky-API hits across 24 files.
