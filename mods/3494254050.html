What it is #

A client-side chat extension for Puck: an expanded quick-chat wheel/menu, extra quick-chat entries and a settings page where the player edits their own quick-chat list and key bindings. It ships only one managed assembly and one JSON config file it creates on first run. None of the game's simulation or server authority is touched — the patches only intercept local input, the local pause menu and the local quick-chat UI path.
