Verdict: BENIGN / WITH CAVEATS Risk score: 34/100 (Moderate) Kind: managed .NET mod + asset payload (3 MP3 ping sounds, PDB symbols) Author: 76561198067045734 · Published/updated: 2025-09-25 05:54 UTC · Subscribers: 132,418 · On-disk size: 0.57 MB

What it is #

A large client-side quality-of-life bundle: configurable key binds and chat macros, rich-text/markdown/kaomoji/custom-emoji chat rendering, local mute of individual players, scoreboard conveniences (copy SteamID, open Steam profile) and per-player ping/jingle sounds. Most of the code is UI and input work, but it ships a genuinely capable downloader: a user-editable links.txt of image URLs (seeded with default links to files.catbox.moe) whose images are downloaded and cached locally as chat emoji.

Contents #

  • 5 files / 602,598 bytes: PoncePlayerInput.dll (393,216 B), 3 .mp3 ping sounds (PingSounds/*.mp3, e.g. apple-pay-sound.mp3), and a .pdb debug-symbols file that should not normally be shipped to users.
  • PoncePlayerInput.dll — managed .NET (dotnet=1), PE32 machine=i386, signed=0, sections .text/.rsrc/.reloc, overlay 0, entropy 5.66 (normal IL).
  • All hashes are in evidence/hashes_sha256.txt; PE facts in evidence/pe_info.txt; decompiled source in sources/.

Findings #

  1. Downloads files from URLs listed in a user-editable links.txt, with default links to files.catbox.moe — CustomEmojiPack.cs:46 (defaults), :534-643 (parse), :693-703 (download + write to EmojiCache). The downloader itself will fetch whatever URL the file lists; the saved bytes are then filtered to image extensions and only loaded as textures. Severity: medium (arbitrary remote content fetch triggered automatically on startup for seeded links; primary trust anchor is the third-party image host and the shipped default list).
  2. Ships a .pdb debug-symbols file — evidence/FACTS.md (.pdb=1). Not malicious, but unnecessary information disclosure (original source paths/names) and a sign of a sloppy release build. Severity: low.
  3. Writes SteamIDs to the system clipboard — ScoreboardUtil.cs:1612,2543,2870,3219. User-initiated "copy ID" action; no clipboard reading. Severity: informational.
  4. Broad chat/UI patch surface including rich text injection — ChatRichTextPatch.cs:9 and the markdown/kaomoji pipeline (LocalMuteClientMod.cs:729-744 builds <b>/<i>/<color> markup from chat text). Rendered locally; worth noting because chat text is turned into rich-text markup, but it is the mod's advertised feature. Severity: informational.
  5. Steam profile URLs opened through the game's URL opener — ScoreboardUtil.cs:914,4170. User-clicked; opens steamcommunity.com only. Severity: informational.
  6. No credential/token access, no persistence, no process/registry/network-socket capability — 0 hits for the credential/persistence API set across 33 files; evidence/api_surface.txt shows only [Clipboard/Input] matches=4 and [Network] matches=5 (all UnityWebRequest local-file loads plus the URLs above).

Evidence trail #

  • SHA-256 inventory: evidence/hashes_sha256.txt, evidence/inventory.tsv, evidence/FACTS.md; evidence/api_surface.txt (Clipboard/Input and Network categories, 33 types).
  • PE facts: evidence/pe_info.txt (managed, unsigned, no overlay, entropy 5.66). Binary scan: 27 "magic signature" hits — mostly MZ/ZIP byte patterns inside the DLL's compressed metadata/resources and the MP3 payload; no valid embedded PE.
  • Decompilation: complete ilspycmd output, 33 files (sources/); CustomEmojiPack.cs was read in full around the download/allow-list logic.
  • Independent binary REA notes reviewed: _harness/rea/3574337071__PoncePlayerInput.dll.md.
  • Not verified: contents of the shipped default links.txt URLs were not fetched (no live requests made), and the actual cached image bytes were not examined; runtime UI behaviour not executed (game not run by instruction).

Bottom line #

Keep with caveats, and consider editing config/ModHub/PlayerQoL/Emojis/links.txt to remove any link you do not trust — the mod downloads whatever image URLs are listed there (defaults point at a public image host) and only uses them as chat emoji, but it is still automatic fetching of remote content.
