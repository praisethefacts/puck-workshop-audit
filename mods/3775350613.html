Audit 2026-10-26

Verdict: BENIGN (with provenance caveat) Risk score: 12/100 (Low) Kind: managed .NET mod Author: unknown — workshop metadata returns nothing (item deleted/unlisted) · On-disk size: 7.04 MB

What it is #

A referee/rules client for TLAN league play: a penalty HUD, ref signal panel, scoreboard UI and a referee-feedback window, plus message plumbing to a server-side rules mod. The 7 MB is mostly twelve PNG overlay images; the only executable is a 90,624 B managed DLL.

Contents #

  • 15 files: 12 .png, 2 .md (LICENSE / THIRD_PARTY_NOTICES), TLANRulesClient.dll (90,624 B).
  • TLANRulesClient.dll: PE32, i386/AnyCPU, .NET/Mono, unsigned, 3 sections, no overlay, entropy 5.83. 68 decompiled C# files (~205 KB).
  • Hashes: evidence/hashes_sha256.txt; PE facts: evidence/pe_info.txt; source: sources/.

Code analysis #

  • Network: none. No URLs, no UnityWebRequest/HttpClient/WebClient, no sockets in the decompiled code. Communication happens through the mod's own ClientMessenger / Envelope message types over Puck's existing game connection.
  • Referee integrity: the client builds a delimited signature string from SteamID64 + team + vote (_signature.Append('|').Append(...)) for referee-feedback tallies, so the server can verify the report came from the claimed ref. It is a hash/HMAC-style check — no encryption keys, no exfiltration.
  • Filesystem: writes its own settings (HUD position, panel rectangles, toggles) via ClientSettingsStore; reads nothing outside its config.
  • Absent: no HTTP, no DllImport/P-Invoke, no process or registry access, no crypto beyond the signature helper, no obfuscation, no reflection loading, no persistence, no input capture, no credential access.

Findings #

  1. Item no longer exists on the Steam Workshop (metadata result: 9, no title/author/size). You have a copy on disk that can no longer be re-downloaded or compared against a public listing. Severity: moderate (provenance only).
  2. Code review found no malicious behaviour: it is a UI + messaging client. Severity: none.

Evidence trail #

  • Method: SHA-256, PE parsing, full ilspycmd decompilation (68 files read by pattern and by spot-review of every networking/config path), byte-pattern + text scan (0 text hits).
  • Not verified: the server-side counterpart that consumes the signature and messages was not available on disk, so end-to-end protocol behaviour is inferred from the client only.

Bottom line #

Keep or remove — it is harmless code, but the Workshop entry is gone. Because Steam can no longer vouch for the file, only keep it if you got it as part of the TLAN league package.
