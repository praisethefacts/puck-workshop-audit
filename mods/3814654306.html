What it is #

A HUD overlay for Puck that draws a small arrow on the edge of the screen pointing toward the puck whenever the puck is off-screen, so a player can find it without panning the camera.

It is the smallest mod in this set: one 13 KB DLL, five source files, no assets, and no Harmony patches at all.

Code analysis #

OnEnable() warns to the log if a GameObject.Find("RinkPuckIndicator") already exists (guard against a duplicate load), otherwise creates that GameObject, calls Object.DontDestroyOnLoad, and attaches IndicatorBehaviour. Behaviour. IndicatorBehaviour.cs:8 internal sealed class IndicatorBehaviour : MonoBehaviour. Its Update() (:52) returns unless all of: the config's Enabled flag, not a dedicated server (ApplicationManager.IsDedicatedGameServer), the game UI is being shown (SettingsManager.ShowGameUserInterface), the game's UIManager singleton exists with a non-null Hud, and the HUD is visible. It then gets the puck through the game's own manager (:57 MonoBehaviourSingleton<PuckManager>.Instance.GetPuck(false)) and calls _arrow.Track(Camera.main, puck.transform.position). A ProbeRoot() routine re-attaches the arrow into instance.RootVisualElement every 0.5 s so it survives HUD rebuilds (e.g. after instance.GameState.View changes).

Rendering. PuckArrow.cs builds the arrow entirely in code as a VisualElement named "RinkPuckIndicatorArrow" and draws a 2 px black outline with UI Toolkit's Painter2D (MoveTo/LineTo/ClosePath/Fill/Stroke). When the puck is off-screen it converts camera.WorldToScreenPoint through RuntimePanelUtils.ScreenToPanel, computes the bearing with Mathf.Atan2, clamps the position to the HUD edge (OutlineWidth = 2f, MinimumEdgeGap = 6f) and rotates the arrow. No external textures, no shaders, no asset loads.
