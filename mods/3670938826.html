Verdict: CLEAN Risk score: 6/100 (Low) Kind: managed .NET mod Author: 76561199382528995 · Published/updated: 2026-02-21 22:43 UTC · Subscribers: 52,669 · On-disk size: 0.04 MB

What it is #

A small competitive-skating tweak for Puck: it changes the skating/dashing movement model (including suppressing the game's native dash in favour of its own), adds a rhythm/stride tracker and a small settings UI, and includes a handshake so clients can tell whether the server also has the mod installed.

It is the smallest mod in this set — 12 source files, one 40 KB DLL, no assets.

Code analysis #

Bootstrap. CompetitiveSkating/PuckCompetitiveSkating/SkatingPlugin.cs implements IPuckPlugin; OnEnable() creates a Harmony, patches, and creates a persistent UIBootstrapper/ModSyncManager; OnDisable() unpatches and destroys them.

Harmony patches — 5, all movement/input related. FixedUpdate_Patch.cs:10 [HarmonyPatch(typeof(PlayerBody), "FixedUpdate")], PlayerBody_Awake_Patch.cs:6 [HarmonyPatch(typeof(PlayerBody), "Awake")], OnDestroy_Patch.cs:7 [HarmonyPatch(typeof(PlayerBody), "OnDestroy")], UpdateInputs_Patch.cs:10 [HarmonyPatch(typeof(PlayerInput), "UpdateInputs")], and NativeDashSuppression_Patch.cs:9 [HarmonyPatch] which resolves the game's own dash methods at runtime by name — NativeDashSuppression_Patch.cs:15 AccessTools.Method(typeof(PlayerBody), "DashLeft", …) and :20 … "DashRight" — so it can neutralise the native dash and substitute its own. Body physics work runs server-side only: FixedUpdate_Patch.cs:93 and :351 bail unless NetworkManager.Singleton.IsServer and the player is a skater. Supporting both the new (1235) and old (897) game builds is why the dash hooks are resolved by reflection rather than by a hard attribute.

Network — netcode only, and only a two-message handshake. ModSyncManager.cs (a MonoBehaviour) registers two named messages inside the existing lobby session: "CompSkate_Ping" server-side → replies "CompSkate_Pong" (ModSyncManager.cs:59–:74), and "CompSkate_Pong" client-side → sets SkatingPlugin.IsServerModded = true (:85–:95). Its only purpose is to warn a client when the server lacks the mod (:111), so mismatched skating physics are not silently desynced. There is no HttpClient, WebClient, WebRequest, UnityWebRequest, Socket, TcpClient, UdpClient, Steam API call, URL, hostname or port anywhere in the 12 files — evidence/api_surface.txt has no [Network] section for this mod.

Filesystem — none. evidence/api_surface.txt has no [FileSystem] section; there is no System.IO usage, no config file, no log file, no cache directory. The settings UI (CompSkatingUI.cs) exists only in memory for the session.

Absent categories (checked against evidence/api_surface.txt and all 12 sources). No filesystem access of any kind (nothing read, nothing written, nothing deleted). No network APIs of any kind. Findings #

  1. Replaces the game's native dash with its own implementation (NativeDashSuppression_Patch.cs:9–:20, PlayerBody_Awake_Patch.cs:6, FixedUpdate_Patch.cs:10). This changes how players move — which is the mod's entire purpose — and it must be installed on the server for the physics to be authoritative. Not a security concern, but it means the mod materially changes game behaviour. Severity: informational (by design).
  2. Two-message CompSkate_Ping/CompSkate_Pong handshake (ModSyncManager.cs:59–:95) to detect a mod-less server. The ping carries no payload beyond the handshake and the pong only sets a boolean. Severity: informational (positive: it warns instead of desyncing silently).
  3. No files on disk, no config, no logs. Nothing to persist, nothing to tamper with. Severity: informational (positive).
  4. Reflection on two game method names rather than hard attributes (NativeDashSuppression_Patch.cs:15/:20) — present only to support two game builds, and it resolves methods on typeof(PlayerBody), a game type. Not dynamic code loading. Severity: informational.
  5. Automated scan is clean: evidence/hits_summary.txt records magic-signature hits: 0 ; keyword hits: 0; the single binary hit is CompetitiveSkating.dll 0 MZ (the DLL's own PE header) and there are zero text-pattern hits. Severity: informational.

Bottom line #

Keep. It is a 40 KB movement tweak: five Harmony patches on player body/input, one in-lobby ping/pong handshake so you are told when the server is running a different build, and literally no filesystem, network client, registry, crypto or persistence code. The only reason to think twice is that it replaces the game's dash physics, so servers and clients should be running the same version.
