What it is #

A sound-effect pack that replaces/augments stick and puck impact sounds (grounded/ungrounded stick, puck collisions) with its own .wav files. The DLL hooks the relevant game sound trigger points and loads its WAVs from a local StreamingAssets/sounds folder; a JSON file configures the mapping. It does not talk to any network or perform any file access outside the game/mod folders.

Contents #

  • 24 files / 3,539,395 bytes: 1 DLL (SoundModWorkshop.dll, 27,136 B), 21 .wav effects, 1 .json config, 1 preview.png (Workshop preview image).
  • SoundModWorkshop.dll — managed .NET (dotnet=1), PE32 machine=i386, signed=0, sections .text/.rsrc/.reloc, overlay 0, entropy 5.48 (normal IL).
  • All hashes are in evidence/hashes_sha256.txt; PE facts in evidence/pe_info.txt; decompiled source in sources/.

  • Audio loading: local files only — SoundModWorkshop.cs:43 (UnityWebRequestMultimedia.GetAudioClip(...)), :46 (SendWebRequest()), with the target path built at :73 and :85 (Path.Combine(...)), and the sound folder resolved at :555 (Path.Combine(<assembly dir>, "StreamingAssets", "sounds")) and :556 (Path.GetFullPath(Path.Combine(Application.dataPath, "..", "StreamingAssets", "sounds"))). This is a file:// load of the pack's own WAVs, not a download; no absolute/arbitrary paths are constructed.
  • Config: the mod's own .json in its folder (read at startup, used to map sound types); no writes outside its directory were found in the decompiled files.

Those are the PNG's embedded tEXt/metadata text chunks (image descriptions/URLs baked into the preview artwork), not code and not fetched by the mod; the rest are byte patterns inside the WAV/PCM data.

Findings #

  1. Three Harmony patches on stick/puck sound trigger points — GameSoundPatches_Workshop.cs:44,87,160. Exactly the advertised feature (custom impact sounds); no gameplay-authority or host-level effect. Severity: informational.
  2. WAVs loaded from a local StreamingAssets/sounds folder — SoundModWorkshop.cs:43-46,73,85,555-556. Uses Unity's UnityWebRequestMultimedia on a file:// target, which trips keyword scanners but performs no network I/O. Severity: informational.
  3. http:// strings inside preview.png — evidence/FACTS.md binary hits. Image metadata text chunks in the Workshop preview art; no code path references the PNG. Severity: informational.
  4. No network/registry/process/crypto capability — 0 risky-API hits across the 5 source files; evidence/api_surface.txt shows no network category except the local-media load.

Bottom line #

Keep. It hooks three in-game sound triggers and plays its own local WAV files; the http:// hits are text inside the preview image, and there is no networking or OS-level access.
