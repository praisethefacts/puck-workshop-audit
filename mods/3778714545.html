Audit 2026-10-26

Verdict: BENIGN (with provenance caveat) Risk score: 12/100 (Low) Kind: managed .NET mod Author: unknown — workshop metadata returns nothing (item deleted/unlisted) · On-disk size: 29.41 MB

What it is #

The main TLAN league client: a public scoreboard/player-directory browser plus custom goal explosions and sounds. 29.4 MB is 58 .ogg sounds, 15 PNGs and one Unity .bundle; the only executable is a 237,568 B managed DLL.

Contents #

  • 75 files: 58 .ogg, 15 .png, 1 .bundle (assets/goalexplosions.bundle), TLANClient.dll (237,568 B).
  • TLANClient.dll: PE32, i386/AnyCPU, .NET/Mono, unsigned, 3 sections, no overlay, entropy 5.93. 140 decompiled C# files (~443 KB).
  • Hashes: evidence/hashes_sha256.txt; PE facts: evidence/pe_info.txt; source: sources/.

Code analysis #

  • Network (HTTPS, all to one domain):
    • https://tlanpuck.com/api/public/scoreboard/players (DirectoryUrl, JSON GET)
    • https://tlanpuck.com/player/<steamId> and https://steamcommunity.com/profiles/<steamId> opened via Application.OpenURL when you click a player (the user consciously navigates).
    • UnityWebRequest.Get / UnityWebRequestMultimedia.GetAudioClip for local .ogg playback (AudioType 14) — the files are on disk, no remote audio download.
  • Filesystem: reads its own assets/* and config; no writes outside the mod's config dir.
  • Notable false alarm: CollectRegistryPaths(...) is the mod's own path candidate list used to locate .abx/bundle assets inside the game folder — it is not the Windows registry. No Registry/Microsoft.Win32 usage exists anywhere in the source.
  • Absent: no plaintext/hard-coded IPs, no HTTP (non-TLS), no DllImport/P-Invoke, no process start, no crypto/obfuscation, no reflection loading, no persistence, no input capture, no credential or Steam-ticket access.

Findings #

  1. Item no longer exists on the Steam Workshop (metadata result: 9). The on-disk copy can no longer be verified against a public listing. Severity: moderate (provenance only).
  2. Only talks to tlanpuck.com over TLS, for scoreboard data. Severity: low (normal).
  3. No malware indicator of any kind. Severity: none.

Evidence trail #

  • Method: SHA-256, PE parsing, ilspycmd decompilation of all 140 files (network/file/process APIs enumerated), byte-pattern + text scan.
  • Not verified: tlanpuck.com scoreboard responses (not exercised); server-side TLAN mod.

Bottom line #

Harmless code, but unlisted on Steam. Keep it only if it came with the TLAN league install; otherwise remove an unverifiable 29 MB client.
