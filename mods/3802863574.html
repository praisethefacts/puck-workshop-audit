What it is #

A custom-arena loader/rink-builder for Puck ("B25"). It scans for arena packs — its own Arenas folder next to the DLL and every Steam Workshop item you are subscribed to — reads each pack's .al.json manifest, and replaces the shipped rink scene with the pack's .glb model (via GLTFast) or Unity .unity3d bundle, repositioning the crowd, goal lights, glass and ice. It adds an "Arena Loader" button to the pause/main menus. It performs no Harmony patching at all; it works through the game's public event API, SaveManager prefs and a small amount of reflection into the game's CrowdManager.

The caveat is bundled analytics: the mod ships deps\RinkApi.dll, a shared heartbeat client (byte-identical to the one in mod 3811996661 "Rink") that POSTs a small "mod is loaded" record to https://rinkpuck.com/api/stats every ~60 s.

Code analysis #

Bootstrap. ArenaLoader.Plugin : IPuckPlugin (Plugin.cs:9), build B25 (BuildInfo.cs:5). A static constructor installs an AppDomain.AssemblyResolve handler: if a reference to RinkApi cannot be resolved normally it reads the manifest resource ArenaLoader.RinkApi.dll and returns Assembly.Load(bytes) (Plugin.cs:24-46). OnEnable creates a DontDestroyOnLoad("ArenaLoader") object, adds ArenaScene, and calls RinkApi.Register("ArenaLoader", "B25") (Plugin.cs:63-67). OnDisable unregisters, destroys the object (:77-86).

Arena discovery. ArenaRegistry.Refresh loads <plugin dir>\Arenas\ (creating it if missing) and then walks SteamWorkshopManager.GetSubscribedItemIds() + GetItemInstallInfo for every subscribed item, one directory level deep (ArenaRegistry.cs:18-96). Each *.al.json manifest is deserialised into ArenaDefinition, must name a model (.glb) or bundle (.unity3d), and encrypted .abx bundles are explicitly rejected with "encrypted .abx bundle, the plain .unity3d one is needed" (ArenaRegistry.cs:128-131). Note this is a materials/asset convention, not a crypto routine: there is no decryption code in this mod.

Loading and scene work. ArenaContent.Instantiate dispatches to InstantiateBundle (AssetBundle.LoadFromFileAsync then LoadPrefab, unloading the bundle afterwards — ArenaContent.cs:55-78) or InstantiateModel (File.ReadAllBytes(modelPath) → GLTFast GltfImport.Load → instantiate — ArenaContent.cs:33-45). ArenaScene listens for Event_Everyone_OnLevelSpawned / OnLevelDespawned / Event_OnSceneUnloaded on level_default (ArenaScene.cs:40-66) and applies the arena: ArenaShipped.Apply hides the shipped Hangar, Spectator Booth, Crowd, Barrier Glass, Ice Top/Bottom renderers, disables probes, tunes lights from AssetInformation.json options, and rebuilds the crowd (ArenaShipped.cs:11-45,100-133), restoring everything on unload (:198). Crowd density/seat placement is done by reflecting private CrowdManager members crowdDensity and crowdPositionMemberMap (ArenaShipped.cs:54,190,203) — reads and writes inside the game's own object graph, nothing else. ArenaTheme.cs:85 likewise pokes PanelSettings.m_FallbackDynamicFonts for the injected UI font. ArenaMenuAccess inserts a Button into UIManager.Instance.PauseMenu/MainMenu UI Toolkit views (ArenaMenuAccess.cs:19-56); ArenaMenu is the settings screen. Selected arena and crowd percent are stored through the game's SaveManager (ArenaSettings.cs:5-31); per-pack options are read from the pack's own AssetInformation.json (ArenaOptions.cs:41-69).

Network: one call site, all of it analytics. The only networking in either assembly is RinkApi.Beat (RinkApi.cs:69-157), reached from RinkApi.Runner.Update roughly every 60 s while the mod is enabled (:14-27). It builds

{"action":"mod_heartbeat",
 "data":{"api":1,"kind":"client|server","sid":<SteamID64>,"name":<player name>,
         "server":<MachineName or server name on dedicated servers>,"mods":{"<mod>":"<build>"}},
 "time":<UTC ISO-8601>}

and POSTs it to https://rinkpuck.com/api/stats with header x-rink-key: iZIcx2y-h29cC2GNes4SI03qtNSrK8vh (a shared constant, RinkApi.cs:29-31,144-151). Client identity comes from SteamIntegrationManager.GetSteamId() and the local Player.Username (:101-127); on dedicated servers it sends Environment.MachineName (overridden by the server's public name when available) instead. The response body is never read or parsed — there is no remote control channel. No opt-out switch exists: Register is called unconditionally in OnEnable.

Filesystem / other. Creates <plugin dir>\Arenas\ (ArenaRegistry.cs:43-52); reads manifests, .glb/.unity3d/AssetInformation.json from local and Workshop packs. No writes outside the game's own prefs. No registry, Process, DllImport/Marshal, Assembly.LoadFile, injection, persistence, crypto, clipboard, keyboard or screen access (source-wide grep; the single [Process] hit is an unused using System.Diagnostics; in Properties/AssemblyInfo.cs:1, the [Ransom/Miner] hit is the literal string "encrypted .abx bundle…" at ArenaRegistry.cs:130).

Findings #

  1. Unconditional analytics heartbeat containing SteamID64, player name and mod list to rinkpuck.com every ~60 s (RinkApi.cs:101-151, shared component deps\RinkApi.dll sha256 14d99d29…, identical to the copy in mod 3811996661). On dedicated servers it reports the machine/server name instead of a player. Nothing secret is sent (no ticket, token, cookie, IP logging is server-side), the API key is a public constant, and the reply is ignored, so this is telemetry, not a control channel — but there is no way to turn it off. Severity: moderate.
  2. Embedded-assembly load at runtime. Plugin.cs:24-46 calls Assembly.Load on a resource named ArenaLoader.RinkApi.dll when the RinkApi reference cannot be resolved from deps\. The shipped deps\RinkApi.dll is benign and fully reviewed; the embedded copy's bytes could not be extracted/hashed from the evidence set, so treat "same file" as likely but unproven. No download, no encryption, no reflection-generated code. Severity: low.
  3. Private-field reflection into CrowdManager and PanelSettings (ArenaShipped.cs:54,190,203, ArenaTheme.cs:85) to set crowd density, seat maps and fallback fonts. Local game state only; this is how a non-Harmony mod reaches internals. Severity: informational.
  4. No Harmony patches. All integration is via EventManager listeners and UI Toolkit button injection (ArenaScene.cs:40-66, ArenaMenuAccess.cs:19-32), and everything is unsubscribed/removed in OnDisable/OnDestroy. Severity: informational.
  5. Content trust is local/Workshop only. Any .al.json + model found in the Arenas folder or a subscribed Workshop item will be loaded and its options applied; .glb is parsed by GLTFast and bundles by Unity AssetBundle.LoadFromFileAsync, i.e. assets only, never assemblies. A malicious Workspace pack cannot execute code through this mod. Severity: low.
  6. Absent categories (checked against evidence/api_surface.txt + all 17 decompiled files): no HttpClient/WebClient/raw socket/DNS APIs besides the single UnityWebRequest heartbeat; no registry access; no process creation or shell; no P/Invoke or Marshal; no Assembly.Load(file/bytes) of downloaded code; no persistence (Run keys, tasks, services); no crypto/obfuscation of user files; no credential/token/Steam-ticket/cookie/clipboard/keyboard/screen access; no stealth or AV-evasion behaviour.

Bottom line #

Install-safe arena loader with no code-execution, persistence or file-encryption behaviour — its one real caveat is that it phones home to the author's site (rinkpuck.com) every minute with your SteamID64, display name and installed-mod list, with no toggle to disable it.
