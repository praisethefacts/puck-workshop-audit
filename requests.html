Request form

What should be checked?

Paste a Steam Workshop URL, a steam:// link, or the numeric published file ID.

Comma-separated reasons are fine: new binary, unexpected network traffic, changed after an update, odd permissions. Do not paste private data.

Open GitHub issues directly

Submitting creates a public GitHub issue. The form does not upload files; only the Workshop reference, your note and optional contact are sent. Requests are queued, not guaranteed.

What happens next

Public, checked, queued.

  1. 01
    The ID is parsed.

    Raw IDs, Steam Community URLs and steam:// links are accepted. Junk fails before anything is posted.

  2. 02
    Steam confirms it exists.

    The public Workshop API must return a live item. Deleted or unlisted items are rejected.

  3. 03
    An issue is opened.

    The request lands in the mod-request queue on GitHub with the Workshop link, the reason and the request time.

Ground rules

One mod per request. No private packs, leaked builds or paid content. A request is not a promise or a priority ticket; the queue is public so it can stay honest.
