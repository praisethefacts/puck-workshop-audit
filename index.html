01

Scope and verdict

No malware. Six findings that still matter.

The headline is deliberately plain: no token or credential grabber, stealer, ransomware, miner, RAT, persistence mechanism, code injection or evasion was found in any of the 63 installed mods.

What the audit did find is more ordinary and more nuanced. One mod deliberately fingerprints machines over plain HTTP. Fourteen carry privacy, telemetry or capability caveats. Two no longer have verifiable Workshop provenance. The rest are game logic, stat trackers, audio packs, reskins and UI tweaks.

Every verdict is tied to a file inventory and SHA-256 hashes. Managed code was decompiled and read, not just scanned. The reports are triage: they describe what the reviewed bytes can do, and where a verdict depends on a hash that a future Workshop update can change.

02

Key findings

What the clean verdict is not hiding.

Ranked by security relevance, with the affected records linked. A low score is not the same as “nothing to see here”; read the caveats before installing.

  1. 01
    3735183385 Admin Panel

    FIXED - now CLEAN (was SUSPICIOUS). Admin Panel's server-side handler used to execute AdminPanelCmd from any connected client and trusted a client-supplied SteamID. Build B55 (updated 2026-10-26 22:17 UTC) resolves the sender to a server-side Player, authorises via AdminLevel / admin_steam_ids.json / AdminManager, refuses and logs non-admins, ignores the client-supplied SteamID, and blocks vote-kicks against admins. Re-audited: no malware capability before or after.

    Risk12/100
  2. 02
    3776968217 RHL Companion

    SUSPICIOUS — deliberate machine fingerprinting. Obfuscated MultiAccountGuardClient.dll (anti-multi-account guard) reads SystemInfo.deviceUniqueIdentifier, steamId, a volume serial + enumerated module list, and POSTs the fingerprint over plain HTTP to a raw IP (http://155.212.135.111:8081/report) plus HTTPS to rhladminpanel.morfikgl.beget.tech with an X-Api-Key. The obfuscated string table was decoded offline: no credential, wallet, keylog, screen or file-exfiltration logic exists — it is a hardware-ID ban-evasion check, not a stealer.

    Risk45/100
  3. 03
    7 mods

    Privacy — third-party uploads. Seven community mods phone home: full installed-mod inventory to the game server (3784458679), SteamID64 heartbeat to puckstats.io + cached server passwords in a local JSON (3497550964), chat lines to Google Translate (3822871103), SteamIDs to a logging backend (3574337071), and match/positional replay telemetry to rinkpuck.com (3815478693, plus the shared RinkApi.dll heartbeat in 3802863574/3811996661), and SteamID64 + persona name + ranked chat text over plain HTTP to a community matchmaking IP (3793631096 RankUp).

    Risk15–34/100
  4. 04
    3775350613, 3778714545

    Unverifiable provenance. Two TLAN client mods are no longer listed in Steam's Workshop API (result: 9), so author/size cannot be confirmed. Code reviewed and clean.

    Risknote
  5. 05
    2 mods

    Capability, not malware. 3566470321 decrypts third-party .abx map bundles (AES + HMAC-SHA256) and ships base64 chat payloads — a legitimate load-and-sync design, but an arbitrary-bundle loader. 3800009738 embeds a WebView2 browser plugin plus a script that downloads uBlock Origin into the game folder and renders remote MOTD pages, so it can display anything the operator hosts.

    Risk24–25/100
  6. 06
    45 mods

    Everything else is ordinary modding — game logic, stat trackers, audio packs, rink/arena/pad/puck reskins, UI tweaks. All unsigned (normal for Puck), none obfuscated, none touch credential or wallet paths.

    Risk≤16/100
